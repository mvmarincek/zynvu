# Código de conduta

Participe com respeito. Críticas devem tratar do trabalho, não de características
pessoais. Assédio, discriminação, ameaças e divulgação de dados privados não são
aceitos. Mantenedores podem moderar conteúdo e limitar participação por violações.
Relate incidentes aos mantenedores pelos canais privados disponíveis no GitHub.
