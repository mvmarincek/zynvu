# Test matrix

## Hardware fixtures
CPU-only 4GB/8GB/16GB/32GB; NVIDIA 4GB/8GB/16GB VRAM; integrated/shared GPU; Apple unified memory; Windows/Linux/macOS; VM with/without GPU; missing drivers; low disk; battery-constrained; unavailable runtime. Ensure graceful no-fit results.

## Recommendation quality
Reject incompatible OS/driver/quantization/license, tool-calling schema failures, unsafe memory overcommit. Verify sequential/concurrent peak estimates and alternatives. Deterministic ranking reproducible with fixed catalog.

## Integrations
GitHub/Slack/Linear/Render/Vercel metadata, missing OAuth scope, expired tokens, offline network, API rate limit, untrusted tool result injection, denied write action. Verify VOKI denies all software UI executors.

## Memory and learning
Folder isolation, backup/migration, PII removal, duplicate memory consolidation, skill validation, index rebuild, corrupted DB recovery, no automatic fine-tune on unsuitable hardware.

## Commerce
Invalid SKU, forged webhook, duplicate event, out-of-order events, provider retry, lost redirect, delayed Pix confirmation, email outage, chargeback/refund, admin RBAC, test/prod credential separation, logs redaction, order state consistency.
