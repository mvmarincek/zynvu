# Changelog

## 0.2.0 — 2026-10-26

- ZYNVU Studio substitui a interface Tkinter por frontend web local responsivo.
- Identidade visual escura/verde-lima, ícones, badges, estados e comparação de perfis.
- Catálogo visual, requisitos avançados validados, exportação e feedback de mudanças.
- Sessão local temporária com proteção de origem e CSP, mantendo SDK/API separados.

## 0.1.0 — 2026-10-25

- Fundação Apache-2.0, core/SDK e CLI locais.
- Catálogo de conversa/código com revisões oficiais e hashes.
- Diagnóstico Windows, estimador, ranking, no-fit e exportação validada.
- Políticas HID-only e remoção de padrões comuns de segredos.
- Interface Tkinter inicial e API loopback autenticada.
- Testes e CI. Runtime, catálogo multimodal e comércio permanecem no roadmap.
